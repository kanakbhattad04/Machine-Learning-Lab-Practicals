# Lab 9: K-Means and Hierarchical Clustering

## Aim
To implement K-Means and Hierarchical Clustering algorithms using the Wholesale Customers dataset and analyze customer spending patterns.

## Dataset
Wholesale Customers Dataset

## Algorithms Used
1. K-Means Clustering
2. Hierarchical Clustering

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SciPy

## Steps Performed
1. Loaded and explored the dataset.
2. Selected relevant spending features.
3. Applied feature scaling using StandardScaler.
4. Used the Elbow Method to identify the optimal number of clusters.
5. Implemented K-Means clustering.
6. Implemented Hierarchical clustering.
7. Visualized clusters using PCA.
8. Compared cluster sizes and spending profiles.

## Evaluation and Visualization
- Elbow Method
- Silhouette Score
- Dendrogram
- PCA Scatter Plot
- Cluster Size Comparison
- Average Spending Profile

## Files
- `Lab_9_KMeans_Hierarchical_Clustering.ipynb` – Complete implementation and visualizations.

## Conclusion
K-Means and Hierarchical Clustering were implemented to group wholesale customers based on their spending behaviour. The clustering results help identify different customer segments.
