# Lab 5: K-Nearest Neighbor (KNN)

## Aim
To implement the K-Nearest Neighbor algorithm for classification and regression.

## Dataset
Pima Indians Diabetes Dataset (`diabetes.csv`).

## Algorithms and Techniques
- KNN Classification
- Feature scaling using StandardScaler
- Evaluation using accuracy, precision, recall, F1-score and confusion matrix
- Comparison of different K values
- Cross-validation
- Hyperparameter tuning using GridSearchCV

## Tools and Libraries
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
